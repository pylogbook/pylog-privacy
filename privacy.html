プライバシーポリシー

最終更新日: 2026年9月30日

Pylog（以下「本ツール」）は、運営者本人が自分の Google アカウントのデータを扱うための個人用ツールです。

取得する情報

本ツールは、運営者本人が許可した範囲で、本人の Gmail・Google ドライブ・Google カレンダーのデータを読み書きします。

利用目的

取得した情報は、運営者本人の業務の整理（メールの仕分け、ファイルの保存、予定の管理）にのみ使います。

第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。広告にも使いません。

保存と削除

データは運営者本人のコンピューターと Google アカウント内にのみ保存します。許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。
